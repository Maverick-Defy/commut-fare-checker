Pricing

Defaults come from the November 2026 Event Carpooling proposal.

  • Distances are road distances without traffic.
  • Prices are a draft model pending validation.
  • Place search and routing use free public map services (OpenStreetMap Nominatim, Photon and OSRM). Please use lightly and internally only.
  • Formula: journey cost = allowance + km x rate. Base fare = journey cost ÷ seats. Fee = base x fee %. VAT = fee x VAT %. Total = base + fee + VAT, rounded to whole naira.
